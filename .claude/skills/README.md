# Frontend skills for this repository

This project uses Django templates, Tailwind CSS CDN, and vanilla JavaScript. The skills below adapt guidance from [Effeilo/claude-code-frontend-skills](https://github.com/Effeilo/claude-code-frontend-skills) to this stack.

- `front-a11y/SKILL.md`: accessibility audit/fix checklist for HTML templates.
- `front-refactor/SKILL.md`: safe CSS/JavaScript refactoring workflow.

These are project-local guidance files for AI coding tools and contributors; they do not install a new runtime dependency or automatically install skills globally. Review the upstream repository's license and installer instructions before copying or installing its full skills collection.
